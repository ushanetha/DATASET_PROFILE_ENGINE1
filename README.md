# Dataset Profiling Engine - Browser Version

Run locally:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the browser URL shown by Streamlit.

Features:
- CSV, Excel and JSON upload
- Dataset preview
- Schema and data types
- Missing values
- Duplicate records
- Unique values
- Numerical statistics
- Categorical summary
- Distribution charts
- JSON report download

Deployment:
Upload `app.py`, `dataset_profiler.py`, and `requirements.txt` to GitHub, then deploy the repository with Streamlit Community Cloud.
